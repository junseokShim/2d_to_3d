VB = width of the flank wear land normal to the cutting edge (ISO 8688-2 / ISO 3685), per row of the rectified flute image; reference line = straight line fitted on the unworn part of the cutting edge; VB dimension lines run from the edge to the wear front. End-face wear area = worn pixels of the end-face photo (network classes flank wear / chipping / adhesion, else the brightness rule) / (px/mm)^2, teeth split by the k-fold symmetry of the end face. U = k*u_c, k = 2 (~95 %); u_c = RSS of scale, edge localisation sqrt(2)*sigma/(px/mm) (sigma 0.5 px auto, 1 px manual), repeatability and helix angle +-2 deg. Decision rule ISO 14253-1: conform if VB+U < limit, nonconform if VB-U > limit.
